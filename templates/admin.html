SECURITY MODEL

How the demonstration works

01 — Token Generation

A token is represented using randomly generated qubit values, measurement bases and trap positions.

02 — Verification

Qiskit Aer is used to simulate quantum-circuit execution and trap verification.

03 — Attack Simulation

A malicious disturbance can be introduced to demonstrate how trap errors can reveal tampering.

04 — Token Recovery

An invalidated token can be replaced with a newly generated token.
